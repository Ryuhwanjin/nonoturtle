# NoNoTurtle 🧍‍♂️🐢
> macOS 상단 메뉴바 거북목 방지 & 자세 개선 도우미

<p align="center">
  <b>바른 목 정렬을 유도하는 가볍고 빠른 macOS 네이티브 메뉴바 애플리케이션</b>
</p>

---

## ✨ 주요 기능

- **사람 옆모습 60fps 자세 애니메이션**: 머리, 목(경추), 등(굽은 등), 어깨의 실시간 변화 시각화
- **수직 기준선 (Plumb Line)**: 귀-어깨 정렬선과 전방 돌출 거리(`+X.X cm`) 직관적 표시
- **스마트 자세 타이머**:
  - 설정한 시간(15분 / 30분 / 45분 / 60분) 동안 정자세에서 서서히 거북목으로 변화
  - 타이머 완료 시 macOS 네이티브 시스템 알림 & 사운드 발송
- **타이머 미설정 모드 (루프)**: 타이머를 끄면 알림 없이 8초 주기로 정자세 ↔ 거북목 느린 순환 애니메이션 재생
- **30초 턱 당기기 (Chin Tuck) 가이드**: 5초씩 3회 반복하는 대표적 거북목 교정 인터랙티브 루틴
- **원클릭 자세 재정렬**: 언제든 클릭 시 100% 바른 자세로 즉시 복귀

---

## 🚀 빠른 시작

### 1. 빌드 (단 1초 소요)
```bash
./build.sh
```

### 2. 실행
```bash
./run.sh
# 또는
open NoNoTurtle.app
```

### 3. 종료
상단 메뉴바 아이콘 클릭 후 팝오버 우측 상단의 전원 버튼을 클릭하거나 터미널에서:
```bash
pkill NoNoTurtle
```

## 🛠️ 기술 스택
- **Engine**: Native macOS Cocoa (`AppKit` + `WebKit` + `UserNotifications`)
- **Compilation**: `clang` (외부 의존성 없음, 1초 미만 초고속 빌드)
- **UI**: 60fps Vector Canvas + macOS Native Dark/Light 모드 테마
